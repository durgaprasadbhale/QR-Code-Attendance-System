# QR Code Attendance Management System

## 📌 Overview

The QR Code Attendance Management System is a Java desktop application designed to automate student attendance using QR code technology.

The system allows administrators to register students, generate unique QR codes, scan QR codes using OpenCV and ZXing, mark attendance automatically, generate Excel reports, and send attendance notifications through email.

---

## 🚀 Features

- Student Registration
- Student Management
- QR Code Generation
- OpenCV + ZXing QR Scanner
- Automatic Attendance Marking
- Duplicate Attendance Prevention
- Daily Attendance Reports
- Monthly Attendance Reports
- Excel Export
- Email Notifications
- MySQL Database Integration

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/durgaprasadbhale/QR-Code-Attendance-System.git
```

### Open Project

Import into IntelliJ IDEA as a Maven Project.

### Configure Database

Update:

```
DBConnection.java
```

with your MySQL credentials.

### Configure Email

Update:

```
EmailService.java
```

with your Gmail address and App Password.

### Run

```
LoginUI.java
```
